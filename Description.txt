Общее описание: web ui для подбора земельных участков выставленных на torgi.gov.ru (ГИС ТОРГИ), их анализа и выгрузки данных в yougile crm.
Основной стек: Laravel, Sqlite.


Нужно одностраничное веб-приложение, для отображения данных из разных ресурсов на одной странице:
Источник основных данных:

Пример GET запроса

https://torgi.gov.ru/new/api/public/lotcards/search?biddType=ZK&priceMinFrom=1&priceMinTo=2300000&lotStatus=PUBLISHED,APPLICATIONS_SUBMISSION&pubFrom=2026-08-18&pubTo=2026-08-19&catCode=301&matchPhrase=false&typeTransaction=sale&byFirstVersion=true&withFacets=true&page=2&size=10&sort=firstVersionPublicationDate,desc

Где:

biddType ZK (жестко задан в коде, нет в интерфейсе)
priceMinFrom - начальная цена (вывести в ui, числовое поле от 0, по умолчанию 1)
priceMinTo - конечная цена (по умолчанию 2300000)
lotStatus - жестко в коде без ui
pubFro дата публикации от - сделать датапикер (по умолчанию текущая дата)
pubTo дата публикации до - сделать датапикер (по умолчанию текущая дата) (без возможности выбрать дату больше текущей)
catCode служебное значение
matchPhrase служебное значение
typeTransaction жестко задано без ui
byFirstVersion жестко задано без ui
withFacets жестко задано без ui
page - номер загруженной страницы (будет меняться по ходу парсинга)
size кол-во элементов, больше 10 не возвращает, поэтому всегда 10, служебное значение жестко задано без ui
sort жестко задано без ui

в content массив элементов: каждый элемент сохраням в sqlite по идентификатору лота пример: "id": "22000062030000003021_1" (у каждого свой номер - не числовое значение).
Сохраняемые поля:
"noticeNumber" - у каждого "noticeNumber" может быть много лотов
"lotNumber"
"biddForm" - "code"
"biddForm" - "name" - тип торгов
"lotName"
"priceMin"
"biddEndTime" - Дата окончания подачи заявок
"lotImages" - массив с идентификаторами изображений (сохранить как json или через разделитель для дальнейшего обращения)
"characteristics"[0] - "characteristicValue" - "name" - Основной вид разрешенного использования
"characteristics"[1] - "characteristicValue" - Кадастровый номер (строка в формате 50:32:0090201:2546)
"characteristics"[2] - "characteristicValue" - Площадь м^2
"etpCode" - код торговой площадки (может отсутствовать)
"createDate" - дата публикации
"noticeFirstVersionPublicationDate" - Дата первой публикации извещения (извещения часто переподаются)
"lotVat" - "name" - (информация о НДС)

# Описание Приложения:

(Подключить дополнительные библиотеки для стилей и элементов ui при необходимости).

Слева по нажатию на кнопку фильтра выдвигается сайдбар с фильтрами (с эффектом затемнения и блюра) и внизу кнопка загрузить. Элементы фильтра берутся из параметоров get запроса описанных выше.

На главной странице происходит загрузка первой станицы резульаттов (10 лотов) ниже под результатами пагинация (из "totalPages")

С списке результатов краткие карточки: Миниатюра первого изображения из массива, Кадастровый номер в качестве наименования, Начальная цена в рублях, под ценой мелко инфа об ндс, площадь, Адрес, Основной вид разрешенного использования, Электронная площадка, Дата и время окончания подачи заявок ("Осталось: " и таймер с обратным отсчетом (подключить плагин если нужно, продумать чтобы не глючило) и под таймером сама дата и время - если истекло - красным цветом).
Кнопка выпадающего меню: там действия:
"Не интересно" - тогда карточка сворачивается до отображения одного кадастрового номера и становится блеклой.
"На доску" - действие создает в crm системе карточку на канбан-доске (пока описать общее поведение интеграции с yougile API (https://ru.yougile.com/api-v2#/) - авторизационные данные yougile должны вводиться на отдельной странице настроек пользователя (реализовать бозовую авторизацию на laravel - у каждого пользователя может быть свой доступ к yougile) - описать логику создания карточки с данными лота на доске) (если данные yougile не заполнены, кнопка "На доску" не активна)  - так же ставит флажок на карточку из изображения по адресу resources/img/yougile2.avif (круглая иконка) и пункт "На доску" у такой карточки уже не активен.

Оформить карточки красиво и удобно, более важная инфа крупнее, но в общем карточки сжаты по формату.

При нажатии на карточку лота разворачивается модальное окно с развернутой информацией о лоте (всё тоже но дополнить инфой из второго запроса).
Swiper слайдер изображений с lazy load, если их более одного.
Название этп теперь ведет на адрес "etpUrl".
Ниже список ссылок на файлы документации (только "fileName" c иконкой файла и при нажатии, если это pdf, то отобразить через pdf js в новой модалке).

Внутри раскрытой карточки тоже есть выпадающее менб с теми же действиями, и выбор "Не интересно" внутри раскрытой карточки закрывает текущее модальное окно лота.

Все перечисленные выше данные лота сохраняются в бд. Изображения отображаются по прямой ссылке стороннего ресурса и кэшируются на клиенте, pdf файлы тоже на клиенте, но файлы офисных документов при нажатии на ссылку скачиваются на сервер, через headless libreOffice конвертируются в pdf и отдаются клиенту и кэшируются у него и сохраняются на сервере, при повторном нажатии конвертация не повторяется а отдается из кэша если есть, если нет то из сервера, если нет, то снова конвертируется на сервере.
Напротив каждого файла из списка есть значек скачать, по которому уже происходит переход на оригинальную ссылку ресурса.
Записи лотов в бд старше 20 дней удаляются по каждодневному заданию вместе с привязанными файлами.

Если карточка лота была раскрыта, то лот в бд помечается как "просмотрено" и на карточке лота ставится соответствующий флажок.

При каждой загрузке данных происходит сверка с данными в бд и если "createDate" прежний то отображать данные из бд (даже если было помечено как "не интересно" все равно отобразить, но в блеклом укороченном виде. Если "createDate" изменилась, то все данные лота обновить.

Далее ниже загруженных данных разместить блок со вкладками (tabs), (Каждый подгружается только после ее открытия) (контент вкладок во всю ширину экрана и 2/3 высоты экрана) ( на десктопе кнопка в углу вкладки "во весь экран" (иконка) раскрывает вкладку и активирует полноэкранный режим браузера, в полноэкранном режиме кнопка сменяется на значек "закрыть" (у maplibre есть своя функция map.addControl(new maplibregl.FullscreenControl()); )) (все карты должны открываться на координатах участка земли):
